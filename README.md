# Fusion CAD Assistant

Fusion 360 add-in for parametric watchmaking CAD: screws, jewels, pivots, wheels, pinions, ring gears, springs, **watch cases**, **dials**, finish guides, and anglage.

## Install (no Git required)

1. Click the green **Code** button above → **Download ZIP**.
2. Unzip. Rename the folder to exactly `FusionCADAssistant` if needed.
3. Copy that folder to:
   - **Windows:** `%appdata%\Autodesk\Autodesk Fusion 360\API\AddIns\`
   - **Mac:** `~/Library/Application Support/Autodesk/Autodesk Fusion 360/API/AddIns/`
4. Open Fusion → **Utilities → Scripts and Add-Ins** (`Shift+S`) → **Add-Ins** tab.
5. Select **FusionCADAssistant** → **Run** (optional: Run on Startup).
6. In the **Design** workspace, use the **CAD ASSISTANT** panel.

More detail: see [INSTALL.md](INSTALL.md).

## Requirements

- Autodesk Fusion 360  
- No separate Python install
